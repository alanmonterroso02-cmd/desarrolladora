Marcador y temporizador
inalámbrico para canchas

Un marcador y cronómetro para canchas que se controla de forma inalámbrica desde la banca o la mesa de control, sin cables cruzando la cancha.

Pensado para partidos, entrenamientos y actividades escolares donde se necesita mostrar el marcador y el tiempo de juego de forma clara para jugadores y público.

Características principales

✓ Marcador de puntos visible para jugadores y público

✓ Temporizador para el tiempo de juego

✓ Control inalámbrico desde la banca

✓ Sin cables entre el control y el marcador
